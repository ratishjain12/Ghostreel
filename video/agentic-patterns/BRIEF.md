## Intent

Explain: Most AI agents are just a for loop with a prompt — here are the 8 patterns that
actually make them work (Tool Use, ReAct, Plan & Execute, Agentic RAG, Sequential, Parallel,
Router, Orchestrator-Worker), pulled from the author's own blog post on the topic.

## Assets

- audio/agentic-patterns.wav — the locked voiceover recording, verbatim, source of truth for pacing.
- audio/agentic-patterns-captions.json — word/phrase-level timing for the locked VO.

## Customizations

- VO_MODE: verbatim/locked — narration audio and timing are fixed inputs, not generated by this
  workflow. No TTS step; Step 3.1 is replaced by a manual audio_meta.json built from the existing
  wav + captions.
- GSAP-driven motion per scene (default runtime).

## Notes

- Reel safe zone: keep the caption band and any bottom-anchored content clear of the last
  ~250px of canvas height, and scene content clear of the first ~150px, so platform chrome
  (username, caption bar, action rail) never covers it.
- Design system is pre-seeded: frame.md and assets/fonts/ are already in this project, copied from the house style (blue-professional preset — cream canvas, cobalt #1e2bfa accent, Space Grotesk + Inter). Skip Step 2 (design invention) entirely and go straight from Setup to the storyboard/script step. Every frame's @font-face block must reuse these exact files verbatim (same family names, same weights, same assets/fonts/ paths) — do not have individual frames fetch, invent, or substitute a different font; that mismatch is normally caught and fixed in a later pass, which is pure wasted time here.

- **On-screen text cards — exact copy, one per numbered pattern.** This is a numbered-list
  script (the numbering itself carries real structure — eight named patterns, grouped
  single-agent then multi-agent), so a bold typographic beat card per pattern is appropriate
  here, not decorative. Use this copy verbatim (do not paraphrase or reformat), each card
  entering when its matching narration line starts (read the exact timestamps from
  `audio/agentic-patterns-captions.json`) and exiting before the next card enters — a beat
  card, not held:
  1. `1 TOOL USE` — on "One. Tool use..."
  2. `2 REACT` — on "Two. ReAct..."
  3. `3 PLAN & EXECUTE` — on "Three. Plan and execute..."
  4. `4 AGENTIC RAG` — on "Four. Agentic RAG..."
  5. `5 SEQUENTIAL` — on "Five. Sequential..."
  6. `6 PARALLEL` — on "Six. Parallel..."
  7. `7 ROUTER` — on "Seven. Router..."
  8. `8 ORCHESTRATOR-WORKER` — on "Eight. Orchestrator worker..."
  Then a ninth, different card: `COMMENT GUIDE` — enters on the closing line ("Comment guide
  and I'll send it over") and, unlike the eight beat cards above, **stays held on screen
  through the end of the video** — it's the CTA, not another beat. Consider a subtle visual
  grouping cue between pattern 4 and pattern 5 (e.g. a brief label or divider beat reading
  "SINGLE-AGENT" / "MULTI-AGENT") since that split is real structure in the source, not
  required if it doesn't fit the pacing cleanly.

- **Companion guide (PDF) instructions — applies only to the `/api/generate-pdf` step, not
  to scene authoring.** The guide must give each of the eight patterns (Tool Use, ReAct, Plan
  & Execute, Agentic RAG, Sequential, Parallel, Router, Orchestrator-Worker) its own section:
  a short, correct illustrative code example and a concrete failure case per pattern —
  standard technical-writing content for well-documented patterns (this code does not exist
  yet; authoring it here, from scratch, correctly, is expected and intended — confirmed with
  the user), matching the narration's own promise ("I wrote all eight up with code and the
  failure cases"). Close the guide with a short "Further reading" line linking to the
  author's own blog post, "Agentic Systems Are Just Patterns" by Ratish Jain —
  https://blog.ratishfolio.com/agentic-systems-are-just-patterns — which is now the direct
  source for all eight patterns' definitions (the narration's descriptions are condensed
  from that post), so the guide's explanations should stay consistent with it, not just
  loosely inspired by it.
